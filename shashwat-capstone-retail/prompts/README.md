# Prompt Management Repository

Version-controlled prompts for the Architect Copilot agents.

| File | Agent | Version |
|------|-------|---------|
| `layout_strategist_v1.txt` | Layout Strategist | v1 |
| `market_analyst_v1.txt` | Market Analyst | v1 |

**Usage:** Set `PROMPTS_DIR` to this folder (or clone as a separate Git repo and point env var).

**Versioning:** Bump filename suffix (`_v2`) when making breaking prompt changes; reference version in Langfuse traces.
